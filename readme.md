# Time-Frequency Analysis: Stokes Transformation [with MATLAB Code]

Abstract Since the Stokes Transform (S-transform) was introduced in 1996, it has been widely applied in fields such as medical imaging, physics, and signal processing. In this paper, we demonstrate that the function set (so-called DOST basis) is indeed an orthogonal basis of L2([0,1]) under the Donoho-Stark Theorem (1989) [11]. Our method provides a unified setup where the Stockwell transform (with different allowable windows) and its orthogonal decomposition are studied. Finally, we introduce a fast - O(N logN) - algorithm to compute an allowable window for the Stockwell coefficients. Our algorithm extends Y. Wang and J. Hua (2009) [33].
